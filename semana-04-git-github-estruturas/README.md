# Semana 04 — Git, GitHub, Python local e estruturas de dados

Material de prática da **Semana 04** do curso *Machine Learning e Visão Computacional* (Turma T4, SC TEC / SENAI). Aqui você monta o **ambiente profissional** (Git, GitHub, Python e VS Code) e aprende as principais estruturas de dados do Python.

Nos slides, esta semana aparece como **Módulo 04 — Versionamento e Ambiente**.

## Aulas e exercícios

| Aula | Tema | Pasta |

| 1 | Versionamento com Git e GitHub: zero a hero | [aula1_git_github](aula1_git_github/) |
| 2 | Python local, VS Code e a conexão com o GitHub | [aula2_python_local_vscode](aula2_python_local_vscode/) |
| 3 | Listas, tuplas, dicionários e estruturas compostas | [aula3_listas_dicionarios](aula3_listas_dicionarios/) |

## Dois caminhos para fazer tudo
- **Caminho local:** Git + GitHub Desktop (ou terminal) + Python + VS Code.
- **Caminho Colab:** Google Colab conectado ao GitHub. É uma alternativa completa para quem tem limitação de hardware. Veja o [Exercício 05 da Aula 2](aula2_python_local_vscode/exercicio_05_conectando_o_colab_ao_github/).

## Como estudar
1. Siga os exercícios **na ordem**: a Aula 1 prepara tudo que a Aula 2 usa, e a Aula 2 prepara a Aula 3.
2. Em cada exercício de código, **escreva você mesmo** primeiro; a solução de exemplo fica na pasta para conferir depois.
3. Os seus commits vão para **o seu repositório** (por exemplo, `meu-primeiro-repositorio`), não para este. Aqui é o material de referência.

## Como executar um exercício de código

```bash
git clone https://github.com/Machine-Learning-Visao-Computacional-T4/semana-04-git-github-estruturas.git
cd semana-04-git-github-estruturas
python aula3_listas_dicionarios/exercicio_01_sua_primeira_lista/listas.py
```

No Windows, se `python` não funcionar, use `py`.
