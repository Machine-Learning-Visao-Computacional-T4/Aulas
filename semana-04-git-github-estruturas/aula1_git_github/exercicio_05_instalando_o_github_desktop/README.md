# Exercício 05 — Instalando o GitHub Desktop

**Tipo:** instalação

## Objetivo
Instalar o **GitHub Desktop**, a ferramenta visual que usamos na aula, e conectá-la à sua conta.

## Passo a passo
1. Acesse [desktop.github.com](https://desktop.github.com) e baixe o instalador.
2. Execute o instalador. Ele configura tudo automaticamente.
3. Ao abrir pela primeira vez, clique em **Sign in to GitHub.com** e entre com a conta criada no Exercício 02.
4. Confirme que o seu **nome de usuário** aparece na tela do GitHub Desktop.

## Observação
O GitHub Desktop existe para Windows e macOS. Quem usa Linux pode fazer tudo pelo terminal; os exercícios seguintes mostram os comandos equivalentes.
