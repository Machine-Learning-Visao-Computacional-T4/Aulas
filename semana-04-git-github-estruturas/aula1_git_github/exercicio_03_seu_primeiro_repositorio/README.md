# Exercício 03 — Seu primeiro repositório

**Tipo:** prática no site do GitHub

## Objetivo
Criar o primeiro repositório diretamente pelo site.

## Passo a passo
1. No GitHub, clique no botão verde **New** (ou no ícone **+** no canto superior direito → **New repository**).
2. Em **Repository name**, escreva `meu-primeiro-repositorio` (sem espaços: use hífen).
3. Marque **Add a README file**.
4. Deixe como **Public** e clique em **Create repository**.

## Como saber que deu certo
Você cai na página do repositório e vê o arquivo **README.md** criado automaticamente. Esse arquivo é o "cartão de visita" do projeto: é o primeiro que aparece para quem abre o repositório.

> Guarde esse repositório: você vai usá-lo no Exercício 06 e na Aula 2.
