# Exercício 02 — Criando sua conta no GitHub

**Tipo:** prática no navegador

## Objetivo
Criar uma **conta gratuita** no GitHub, primeiro passo de todo o módulo.

## Passo a passo
1. Acesse [github.com](https://github.com) e clique em **Sign up**.
2. Escolha um **nome de usuário profissional**. Você vai usá-lo bastante, então evite apelidos muito informais. Se o nome já existir, tente variações (nome.sobrenome, nome-sobrenome).
3. Use um **e-mail que você acessa com frequência** e **confirme a conta** pelo link enviado.
4. Quando pedir o plano, escolha **Free** (gratuito). É mais do que suficiente para todo o curso.

## Como saber que deu certo
Ao entrar em [github.com](https://github.com), o ícone do seu perfil aparece no canto superior direito.

## Problemas comuns
- **O e-mail de confirmação não chegou:** olhe a caixa de spam e a de promoções.
- **Nome de usuário já existe:** acrescente o sobrenome ou um número.
