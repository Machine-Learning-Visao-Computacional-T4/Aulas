# Glossário rápido de Git e GitHub

| Termo | O que é |
| --- | --- |
| **Git** | Programa instalado no seu computador que registra o histórico de mudanças dos arquivos. |
| **GitHub** | Serviço online que hospeda repositórios Git e facilita o trabalho em equipe. |
| **Repositório** | Pasta de projeto com todos os arquivos **e todo o histórico**. |
| **README** | Arquivo que apresenta o projeto; é o primeiro que aparece no repositório. |
| **Clone** | Copiar um repositório do GitHub para o seu computador. |
| **Commit** | Um "ponto de salvamento" com uma mensagem explicando o que mudou. |
| **Stage (`git add`)** | Escolher quais mudanças entram no próximo commit. |
| **Push** | Enviar seus commits do computador para o GitHub. |
| **Pull** | Trazer do GitHub as mudanças que você ainda não tem. |
| **Branch** | Linha paralela de trabalho, para experimentar sem afetar a versão principal. |
| **`main`** | A branch principal (a versão "oficial" e estável). |
| **Merge** | Juntar as mudanças de uma branch em outra. |
| **Conflito** | Duas pessoas mudaram o mesmo trecho; é preciso escolher qual versão fica. É normal. |
| **Pull Request** | Pedido para revisar e integrar uma branch na `main`. |
| **Fork** | Sua cópia pessoal de um repositório de outra pessoa/organização no GitHub. |
| **`.gitignore`** | Lista do que o Git **não** deve versionar (senhas, arquivos temporários). |
| **GitFlow** | Modelo de organização de branches (`main`, `develop`, `feature/...`) útil em equipes maiores. |
