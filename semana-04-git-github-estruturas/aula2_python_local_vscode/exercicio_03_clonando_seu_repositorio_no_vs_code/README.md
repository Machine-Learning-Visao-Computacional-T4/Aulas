# Exercício 03 — Clonando seu repositório no VS Code

**Tipo:** prática

## Objetivo
Trazer o repositório criado na Aula 1 para dentro do VS Code.

## O que você precisa
- VS Code instalado (Exercício 02) e Git instalado (Aula 1).
- A **URL** do repositório criado na Aula 1 (botão verde **Code** na página do repositório).

## Passo a passo
1. No VS Code, abra a paleta de comandos com `Ctrl + Shift + P` e digite **Git: Clone**.
2. Cole a **URL** do seu repositório do GitHub.
3. Escolha uma **pasta** do computador para salvar o projeto.
4. Quando perguntado, clique em **Open** para abrir o repositório clonado.

## Se você não fez a Aula 1
Crie rapidamente um repositório pelo site do GitHub (veja o [Exercício 03 da Aula 1](../../aula1_git_github/exercicio_03_seu_primeiro_repositorio/)) e clone-o.

## Problemas comuns
- **"Git not found":** o Git não foi instalado, ou o VS Code foi aberto antes da instalação. Reinicie o VS Code.
- **Pede login:** autentique com a conta do GitHub pela janela que abrir.
