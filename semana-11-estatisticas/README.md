# Kit da Semana 11: Estatística para ML (dados fictícios do BikeFloripa)

- `arquivos/dias.csv`: 731 dias de operação (temperatura, sensação térmica, umidade, vento, chuva, feriado e `alugueis`).
- `arquivos/viagens.csv`: 5.000 viagens (bairro, tipo de usuário, bicicleta, distância, duração, valor e nota).
- `solucoes/aulaN.py`: código de cada aula; `aulaN_saida_esperada.txt` traz a saída real.
- `figuras/`: gráficos gerados pelos scripts.

Instalação: `pip install pandas numpy scipy scikit-learn matplotlib seaborn`.
Execute a partir da pasta do kit (o caminho `arquivos/...` é relativo). Todos os dados são fictícios (sem LGPD).
