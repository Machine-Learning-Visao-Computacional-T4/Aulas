# Guia rápido: branch e Pull Request

1. `git checkout -b feature/nome-da-tarefa`
2. Faça as alterações e rode o script.
3. `git add arquivo.py` e `git commit -m "feat: descrição curta"`
4. `git push -u origin feature/nome-da-tarefa`
5. No GitHub, clique em **Compare & pull request**, escolha a base `main`, descreva o que mudou e quais números você conferiu.
6. Aguarde a revisão e ajuste se pedirem.
