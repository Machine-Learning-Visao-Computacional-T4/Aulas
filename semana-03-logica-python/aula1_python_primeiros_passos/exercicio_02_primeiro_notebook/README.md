# Exercício 02 — Mãos à obra: seu primeiro notebook

**Tipo:** prática no Google Colab · 15 min

## Objetivo
Criar o primeiro notebook no Google Colab e executar a **primeira linha de código Python**.

## O que fazer
1. Acesse [colab.research.google.com](https://colab.research.google.com) (basta uma conta Google) e clique em **Novo notebook**.
2. Renomeie o notebook para `Aula1_SeuNome` clicando no título, no topo da página.
3. Na primeira célula, digite `print("Olá, mundo!")` e execute com **Shift + Enter**.
4. Adicione uma nova célula (botão **+ Código**) e escreva um `print()` com o **seu próprio nome**.

## Como executar

**No VS Code (ou qualquer terminal)**, a partir da pasta raiz do repositório:

```bash
python aula1_python_primeiros_passos/exercicio_02_primeiro_notebook/ola_mundo.py
```

No Windows, se `python` não funcionar, use `py aula1_python_primeiros_passos/exercicio_02_primeiro_notebook/ola_mundo.py`.

**No Google Colab:** abra [colab.research.google.com](https://colab.research.google.com), crie um notebook novo, cole o conteúdo do arquivo `ola_mundo.py` em uma célula e execute com `Shift + Enter`. Quando o programa usar `input()`, uma caixa de texto aparece logo abaixo da célula para você digitar.

## Exemplo de execução

```text
Olá, mundo!
Meu nome é Ana
```

## Dicas e erros comuns
- Dar erro faz parte do processo, não é motivo de vergonha. Leia a mensagem: ela quase sempre diz o que está errado.
- Erros de sintaxe mais comuns no começo: esquecer as aspas, esquecer um parêntese, escrever `Print` com P maiúsculo (Python diferencia maiúsculas e minúsculas).
