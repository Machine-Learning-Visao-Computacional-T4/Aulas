# Exercício 01 — Programe o sanduíche

**Tipo:** dinâmica sem código · 100% por chat/voz

## Objetivo
Vivenciar, **sem código**, por que um computador exige instruções **absolutamente exatas**: a essência da lógica de programação.

## O que fazer
1. Escreva um passo a passo de **como fazer um sanduíche de pão de forma e queijo**, como se estivesse instruindo alguém que **não entende nada do mundo** (um robô literal).
2. Seja exato: o que é "abrir o pacote"? Em que mão fica a faca? O que acontece se o queijo estiver na geladeira?
3. Troque seus passos com um colega: ele deve executar **exatamente o que está escrito, nada além**. Onde deu errado?
4. Reescreva os passos corrigindo as ambiguidades que apareceram.

## Dicas e erros comuns
- Se o seu passo diz "passe o queijo no pão", um robô literal pode passar a **embalagem** do queijo. Instruções de computador funcionam assim.
- Isso se chama **algoritmo**: uma sequência finita e exata de passos. Programar é escrever algoritmos numa linguagem que o computador entende.
