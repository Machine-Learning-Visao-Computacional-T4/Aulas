# Exercício 01 — Verdadeiro ou falso relâmpago

**Tipo:** dinâmica rápida (reações no chat) · sem código

## Objetivo
Introduzir a ideia de **valores booleanos** (verdadeiro/falso) antes de formalizar o conceito.

## O que fazer
Para cada afirmação, responda **V** ou **F**:

1. O Google Colab exige instalação de programas no computador antes de começar a usar.
2. Em Python, `nome` e `Nome` são consideradas a mesma variável.
3. A expressão `"5" + "3"` resulta em `8`.
4. Todo notebook criado no Google Colab é salvo automaticamente no Google Drive.
5. Um comentário (`#`) em Python é executado junto com o restante do código.
6. A função `type()` serve para descobrir qual é o tipo de uma variável.

Depois confira testando no Python o que for testável (`"5" + "3"`, `nome` e `Nome`...).

<summary>Ver respostas</summary>

1. **F**: o Colab roda no navegador, sem instalar nada.
2. **F**: Python diferencia maiúsculas de minúsculas.
3. **F**: com textos, `+` junta: `"5" + "3"` dá `"53"`.
4. **V**.
5. **F**: o comentário é ignorado.
6. **V**.

## Ideia da dinâmica
Cada afirmação é **verdadeira ou falsa, e nada no meio**. É exatamente isso que o Python chama de valor booleano (`True`/`False`).
