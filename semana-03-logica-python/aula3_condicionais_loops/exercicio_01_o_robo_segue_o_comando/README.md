# Exercício 01 — O robô segue o comando

**Tipo:** dinâmica sem código (câmeras ligadas ou reações no chat) · 10 min

## Objetivo
Vivenciar a diferença entre uma **decisão (condicional)** e uma **repetição (loop)** antes de aprender a sintaxe.

## O que fazer
1. Combine um pequeno "código de comandos" com a turma pelo chat. Exemplo: **PULAR** = levantar a mão; **GIRAR** = balançar a cabeça.
2. Instrução condicional: *"SE o seu nome tiver mais de 5 letras, PULE. SENÃO, GIRE."* Todos executam ao mesmo tempo.
3. Instrução de repetição: *"GIRE 3 vezes."*
4. Responda: o que muda entre as duas instruções?

<details>
<summary>Ver resposta</summary>

A primeira foi uma **condicional** (uma decisão: depende de uma condição, e cada pessoa faz uma coisa diferente). A segunda foi um **loop** (uma repetição: a mesma ação várias vezes). É exatamente o que programamos hoje: `if/elif/else` e `for`/`while`.

</details>
