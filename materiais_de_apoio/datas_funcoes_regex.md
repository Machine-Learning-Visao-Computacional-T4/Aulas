# Materiais de apoio

## 1. Datas e fusos horários — Hashtag Programação

Aula sobre fuso horário e conversão entre regiões. Serve de apoio aos exercícios de UTC → São Paulo e Cuiabá. O vídeo usa `pytz`; nosso notebook usa Pandas.

🔗 [Assistir no YouTube](https://www.youtube.com/watch?v=9ucTnvJZVE4)

## 2. Regex — Python Básico Solyd

Aula introdutória sobre expressões regulares em Python. Depois de assistir, podem praticar a identificação e extração de padrões no nosso notebook.

🔗 [Assistir no YouTube](https://www.youtube.com/watch?v=aPk2ruhi2Zk)

## 3. Funções — Gustavo Guanabara

Curso Python, aula 20: Funções — Parte 1. Para acompanhar a introdução à criação e ao uso de funções.

🔗 [Assistir no YouTube](https://www.youtube.com/watch?v=ezfr9d7wd_k)

## 4. VS Code e terminal — Dev C#

O material associado à videoaula aborda abertura de pastas, uso do terminal integrado e navegação no editor. Embora seja de um curso de C#, essa parte ajuda também quem usa Python.

🔗 [Assistir no YouTube](https://www.youtube.com/watch?v=mOtSc3SbavY)

> **Sugestão de atividade:** assistir com o VS Code aberto, reproduzir um exemplo e depois tentar um exercício do notebook sem consultar o gabarito.

## 5. Como utilizar uma função em Python — Hashtag Programação

Mostra como reutilizar uma ação e evitar escrever o mesmo código várias vezes, incluindo chamadas dentro de um `for`.
