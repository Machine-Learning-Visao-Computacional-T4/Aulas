# Exercício 01 — O aluno que decorou a prova

**Tipo:** discussão

## Cenário
Um aluno decorou exatamente as respostas de uma prova antiga, palavra por palavra.

## Pergunta
> O que acontece se a prova nova tiver perguntas **parecidas, mas não idênticas**?

## Passo a passo
1. Responda em uma frase.
2. Agora troque "aluno" por "modelo", "prova antiga" por "dados de treino" e "prova nova" por "dados novos". Reescreva a sua resposta.
3. Que nome técnico tem esse comportamento? (Dica: *overfitting*.)

## Ideia que sustenta a aula
**Decorar** (overfitting) é diferente de **aprender** (generalizar). Um modelo que decora os dados de treino vai muito bem neles e mal em dados novos.
