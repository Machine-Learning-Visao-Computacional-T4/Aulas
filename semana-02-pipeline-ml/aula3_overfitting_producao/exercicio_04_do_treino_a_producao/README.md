# Exercício 04 — Seu problema, do treino à produção

**Tipo:** escrita (síntese de toda a semana)

## Objetivo
Fechar a semana aplicando tudo ao **seu problema pessoal** das Aulas 1 e 2.

## Passo a passo
1. Releia o seu `meu_problema.md` (Aula 1) e as suas métricas (Aula 2).
2. Crie `do_treino_a_producao.md` nesta pasta e responda:
   - Que sinais de **overfitting ou underfitting** poderiam aparecer nesse problema?
   - Que **hiperparâmetro** seria natural ajustar?
   - Como esse modelo seria **implantado** (tempo real, lote ou embarcado)?
   - Que tipo de **drift** poderia surgir com o tempo?
3. Apresente para a turma ou para uma dupla.
4. Faça commit e push.

> Esse é o exercício-síntese da semana: reserve tempo para pensar com calma.
