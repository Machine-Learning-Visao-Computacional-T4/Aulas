# Exercício 04 — Debate: qual métrica usar?

**Tipo:** debate

## Objetivo
Praticar a escolha da **métrica de avaliação** mais adequada ligando o **custo de cada tipo de erro** (falso positivo × falso negativo) ao cenário de negócio. **Não existe uma única resposta certa.**

## Passo a passo
1. Sorteie ou escolha um cenário da tabela abaixo.
2. Preencha as colunas: qual erro é mais caro? qual métrica (ou combinação) você priorizaria? por quê?
3. Apresente sua escolha. Outras pessoas podem **discordar e defender outra métrica**: ouça e rebata com argumentos.

## Dicas
- Para classificação, pense em acurácia, precisão, recall e F1. Para previsões numéricas (como estoque), pense em métricas de regressão.
- Pergunte sempre: *o que acontece se o modelo errar para um lado? E para o outro?*
