# Exercício 05 — Aplique as métricas ao seu problema

**Tipo:** escrita + contraponto de um colega

## Objetivo
Conectar o **problema pessoal** definido na Aula 1 desta semana às métricas vistas hoje.

## Passo a passo
1. Abra o seu `meu_problema.md` da [Aula 1](../../aula1_problema_dataset/exercicio_04_checklist_problema_pessoal/).
2. Crie `metricas_do_meu_problema.md` nesta pasta e responda:
   - O problema é de **classificação ou regressão**?
   - Existe possibilidade de **desbalanceamento de classes**?
   - Qual métrica (ou métricas) você usaria para avaliar um modelo? **Justifique.**
3. Compartilhe com um colega e peça um **contraponto**: ele escolheria a mesma métrica?
4. Faça commit e push do arquivo.

> Guarde: o mesmo problema reaparece na Aula 3.
