# Aula 1 — Do problema ao dataset

**Tema:** definir o problema certo antes de qualquer modelo, coletar dados adequados, explorar (EDA) e preparar o dataset.

| # | Exercício | Tipo | Tempo em aula |
| --- | --- | --- | --- |
| 01 | [Problema mal definido](exercicio_01_problema_mal_definido/) | Discussão | 10 min |
| 02 | [Traduza o problema](exercicio_02_traduza_o_problema/) | Escrita | 12 min |
| 03 | [Leia o gráfico](exercicio_03_leia_o_grafico/) | Interpretação + script | 15 min |
| 04 | [Checklist no seu problema](exercicio_04_checklist_problema_pessoal/) | Escrita (dupla) | 15 min |

Ideia central: **definir bem o problema é a etapa mais barata de acertar e a mais cara de errar.**
