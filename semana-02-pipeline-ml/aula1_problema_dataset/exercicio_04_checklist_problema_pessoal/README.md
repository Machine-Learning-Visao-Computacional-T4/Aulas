# Exercício 04 — Aplique o checklist ao seu problema

**Tipo:** escrita, depois troca em dupla · **Tempo:** 15 min

## Objetivo
Consolidar a aula aplicando o checklist **"Do Problema ao Dataset Pronto"** a um problema do **seu** interesse. Este problema será usado de novo nas Aulas 2 e 3.

## Passo a passo
1. Escolha **um problema** de interesse pessoal, acadêmico ou profissional que poderia virar um projeto de ML.
2. Copie o arquivo [`checklist_template.md`](checklist_template.md) para `meu_problema.md` (nesta pasta) e preencha.
3. Responda em especial:
   - Qual é a **pergunta de ML**?
   - Que **dados existem**?
   - O que a **EDA provavelmente revelaria**?
   - Que **limpeza/transformação** seria necessária?
4. Troque com um colega (dupla ou grupo) e peça **feedback sobre a clareza** da definição do problema.
5. Faça commit e push do seu `meu_problema.md`:
   ```bash
   git add meu_problema.md
   git commit -m "Adiciona meu problema de ML (Semana 02, Aula 1)"
   git push
   ```

> Guarde o arquivo: ele é a base dos exercícios finais das Aulas 2 e 3.
