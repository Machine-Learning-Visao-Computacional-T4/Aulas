# Exercício 01 — O problema mal definido

**Tipo:** discussão (sem gabarito único) · **Tempo:** 10 min

## Objetivo
Perceber que um projeto de ML pode fracassar **não por causa do modelo, mas por causa de um problema mal formulado**.

## Cenário
> Uma empresa pediu para a equipe de dados "usar IA para vender mais". Depois de 3 meses de trabalho, o projeto foi cancelado.

## Passo a passo
1. Leia o cenário com calma.
2. Responda, **mesmo sem saber nada técnico**: *o que pode ter dado errado nesse projeto?*
3. Escreva suas respostas no quadro colaborativo (Miro) da aula ou em um arquivo `minhas_respostas.md` nesta pasta.
4. Para cada problema que você listou, escreva em uma linha **como uma pergunta melhor teria evitado aquilo**.

## Para pensar
- "Vender mais" é medido como? Em quanto tempo? Para quem?
- Alguém sabia que decisão o modelo ajudaria a tomar?
- Que dados existiam para responder a essa pergunta?

## O que você deve levar daqui
Antes de abrir qualquer notebook, **definir o problema é um trabalho sério**. Os próximos exercícios treinam exatamente isso.
